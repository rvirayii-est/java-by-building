# TESDA Programming (Java) NC III — competency mapping

> **Read this first.** This is an *indicative* mapping by competency theme. It is not an official TESDA
> document and does not confer certification. Unit titles and codes change between Training Regulations
> versions; **instructors must verify against the current TESDA Training Regulations (TR) for
> Programming (Java) NC III** before using this for accreditation or assessment. Unit codes are deliberately
> omitted here rather than guessed.

| Competency theme (typical NC III coverage) | Course weeks | Evidence in the repo |
|---|---|---|
| Set up the development environment and tools | 1, 6 | Lesson 01, `docs/SETUP.md`, Git lessons |
| Apply Java programming fundamentals (variables, types, operators, control flow, methods, arrays) | 1–2 | Lessons 01–04, M1 |
| Handle input/output and strings | 2, 5 | Lessons 05–06, 19 |
| Apply object-oriented programming (classes, encapsulation, inheritance, polymorphism, interfaces) | 3–4 | Lessons 09–16, M3 |
| Handle errors and exceptions | 4 | Lesson 16 |
| Use collections, generics and files | 2, 5 | Lessons 07, 17–19, M4 |
| Test and debug programs; write unit tests | 6 | Lessons 21–22, tests in every lesson |
| Use version control and collaborate | 6 | Lesson 23, PR workflow in CONTRIBUTING |
| Design and use relational databases (SQL, JDBC) | 7–8 | Lessons 25–32, M5 |
| Develop web services / REST APIs | 9–10 | Lessons 33–40, M6 |
| Apply application security basics | 11 | Lessons 41–42 |
| Package, deploy and document an application | 11–12 | Lessons 43–48, M7 |
| Work to specification; document and present work | all | `docs/SPEC.md`, per-lesson completion criteria, capstone |

**Assessment aid:** the *Verifiable completion criteria* of each lesson (passing tests + checklist) are
designed to serve as observable evidence an assessor can inspect.
